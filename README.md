# ⚛️ React Hooks Showcase

A collection of 6 mini React projects demonstrating core React hooks. All projects are combined into one single React app with routing for easy navigation.


## 📋 Projects Included

| # | Project | Description | Hooks Used |
|---|---------|-------------|------------|
| 1 | **Accordion** | FAQ accordion with smooth animations | useState, useRef, useEffect |
| 2 | **Background Color Generator** | Change background with preset colors | useState, Events |
| 3 | **Star Rating** | Interactive star rating component | useState, Hover Effects |
| 4 | **Image Slider** | Carousel with auto-play and dot indicators | useState, useEffect, useRef |
| 5 | **Dark/Light Theme** | Theme toggle with Context API | useState, useEffect, Context |
| 6 | **Scroll Indicator** | Progress bar that fills on page scroll | useState, useEffect, Events |

## 🚀 Live Demo

🔗 [View Live Demo](https://react-hooks-showcase-three.vercel.app)

## 🛠️ Technologies Used

- React 18
- React Router DOM (for navigation)
- CSS3 (custom styling)
- localStorage (for theme persistence)
- Context API (for theme sharing)

## 💻 How to Run Locally

```bash

git clone https://github.com/ayeshaafzal13/react-hooks-showcase.git

# Navigate to the project
cd react-hooks-showcase

# Install dependencies
npm install

# Start the development server
npm start
